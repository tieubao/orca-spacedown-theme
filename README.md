# Spacedown Light for Orca

An Orca theme plugin that gives the app and the chat the Spacedown reading palette.

| Role | Color |
|---|---|
| Paper | `#fcfcfc` |
| Ink | `#1a1a1a` |
| Link and focus | `#1d5fd1` |
| Rules and borders | `#e3e3e3` |

Install: Orca, Plugins, install from Git URL `https://github.com/tieubao/orca-spacedown-theme#v1.0.0`. Then pick "Spacedown Light" as the light app theme. For the full look, set the chat font to iA Writer Quattro V at 18 px.

Built from the GitHub Light theme by stablyai (MIT, see LICENSE), with the palette from Spacedown's iA reading theme.
